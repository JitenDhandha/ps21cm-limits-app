# ps21cm-limits-app

This is an interactive tool to visualize published 21-cm power spectrum limits from interferometric experiments, using [eor_limits](https://github.com/EoRImaging/eor_limits) as its backend. It is hosted online at the link: [ps21cmlimits.streamlit.app](https://ps21cmlimits.streamlit.app/).

## To run locally

1. Clone this repository to your local machine.
2. Install the required dependencies in your Python environment of choice. You can do this using pip:

   ```bash
   pip install -r requirements.txt
   ```
3. Run the Streamlit application:

   ```bash
   streamlit run gui.py
   ```
4. Open your web browser and navigate to `http://localhost:8501` to view the application.
